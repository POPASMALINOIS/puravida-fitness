# Rage Training — versión estable

Versión estable actual: **v2.4.24**

Fecha de consolidación: **2026-08-15**

Esta versión de `main` se toma como base estable para continuar el desarrollo.

Incluye, entre otros cambios consolidados:
- Rediseño responsive para escritorio, tablet y móvil.
- Navegación lateral en escritorio e isla inferior en móvil/tablet.
- Calendario semanal tipo Google Calendar con solapes en paralelo.
- Agenda diaria integrada en el dashboard.
- Fichas de clientes integradas en el dashboard.
- Mesociclos y mediciones dentro de cada ficha de cliente.
- Mediciones adicionales configurables.
- Alta de cliente integrada en el dashboard.
- Opción de registrar la cuota inicial como pagada durante el alta.
- Alta de sesiones desde la ficha del cliente.
- Correcciones de navegación para evitar vistas ancladas al cambiar de sección.
- Ajustes responsive en formularios de fecha/hora y listados de clientes/pagos.

A partir de este punto, cualquier cambio posterior debe tratar **v2.4.24 en `main`** como referencia estable hasta que se defina una nueva versión estable.
